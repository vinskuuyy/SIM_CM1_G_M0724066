# SIM_CM1_G_M0724066
Analisis segmentasi pelanggan berbasis metode RFM (*Recency, Frequency, Monetary*) dan algoritma K-Means Clustering pada database Sakila untuk mengelompokkan pelanggan berdasarkan perilaku transaksi. Analisis dilakukan menggunakan R Markdown dengan visualisasi interaktif dan evaluasi cluster menggunakan metode Elbow serta Silhouette Score.
